# Grow Garden Stock App

A Flutter application for tracking and managing garden stocks and plants. This app helps users keep track of their plants, set reminders for watering and maintenance, and provides a user-friendly interface for managing a garden inventory.

## Features

- Plant tracking and management
- Notification system for plant care reminders
- User-friendly interface with glassmorphism design
- Background services for timely alerts

## Technologies

- Flutter
- BLoC pattern for state management
- Local notifications
- Background services
